# Skill: OFT（旷场实验全流程）

## Execution rule / 执行铁律

**Run the scripts in `scripts/` — do not write your own.**
The scripts here are the tested path; ad-hoc code generated by an agent is the
most common source of wrong results. Allowed changes, in order of preference:

1. Pass different CLI arguments (see Parameters below).
2. Copy the script to a scratch dir and make a **minimal** edit for a case the
   CLI cannot express — keep the change small and report exactly what changed.
3. Only if no script covers the task at all: write new code, run it, and then
   **fold it back into `scripts/`** so the next run reuses it.

每次执行前先读 `SKILL.md` 与 `examples/`；不要凭印象重写流程。

（中文摘要：本技能自带的 `scripts/` 是**经过验证的唯一推荐路径**。AI agent 执行时优先原样运行脚本、

## What it does

这是一个**容器技能**，覆盖小鼠旷场实验（Open Field Test）从视频到发表级图表的完整三步流水线：

```
视频 ──▶ [1] tracker_get_data ──▶ step,X,Y CSV
                                     │
                                     ▼
              [2] oft-analysis ──▶ arena_*.png 轨迹图 + arena_*.csv 指标 + 汇总表
                                     │
                                     ▼
              [3] oft-pixelate ──▶ 350px 像素化展示图（可选）
```

## 路由：三步子技能

| 步骤 | 子技能 | 功能 | 详见 |
|---|---|---|---|
| 1 | `1_tracker_get_data/` | 从视频提取轨迹坐标（Tracker 正常导出，或失效时手动逐帧点击录制）；含 Arena 校准与 pixel→cm 换算 | [1_tracker_get_data/SKILL.md](1_tracker_get_data/SKILL.md) |
| 2 | `2_oft-analysis/` | 统计分析：总距离、中心区进入次数/时间、静止时间 + 速度分布验证；输出 300dpi 轨迹图与指标 CSV；多组汇总表 | [2_oft-analysis/SKILL.md](2_oft-analysis/SKILL.md) |
| 3 | `3_oft-pixelate/` | 后处理：高清轨迹图批量缩放到 350px（NEAREST 采样），用于论文拼图 | [3_oft-pixelate/SKILL.md](3_oft-pixelate/SKILL.md) |

**按需进入对应子目录，读其中的 SKILL.md 后执行。** 大多数情况下用户已有 Tracker 导出的 CSV，直接从步骤 2 开始。

## Usage

```bash
# 步骤1（需要视频 + 人工交互，无法自动化批量跑；Tracker 正常时直接用其导出，跳过本步）
cd 1_tracker_get_data
python tracker.py

# 步骤2：单文件分析（输出 arena_{样本名}.png/.csv 到当前目录）
cd 2_oft-analysis
python scripts/plot_oft.py <数据.csv> [--px-per-cm 7.24] [--total-duration 120]
# 步骤2：多组汇总
python scripts/generate_summary.py <results_dir> --output summary.csv

# 步骤3（可选）：像素化
cd 3_oft-pixelate
python scripts/batch_pixelate.py <input_dir> <output_dir> [--width 350]
```

## Input / Output

- **输入**：Tracker 导出的像素坐标 CSV（`step,X,Y`），或步骤1 手动录制的 `record.csv`
- **输出**：`arena_*.png`（300dpi 轨迹图）、`arena_*.csv`（结构化指标报告）、汇总 CSV、像素化 PNG

## Example

```bash
cd 2_oft-analysis
python scripts/plot_oft.py examples/input/6.csv   # 已验证：1159.4 cm / 中心进入 13 次 / 中心时间 15.74%
```

## Dependencies

Python 3.10+：

- 步骤1：`pip install pynput`（tkinter 为标准库自带）
- 步骤2：`pip install matplotlib`
- 步骤3：`pip install Pillow`

## Notes

- 步骤1 需要视频文件与人工逐帧点击，**AI agent 无法本机自动验证**；步骤2、3 均有可跑的 `examples/` 冒烟测试。
- Arena 边界默认 `(908,384,1270,745)`、边长 50 cm，对应用户特定录制设置；更换摄像头/场地后需按步骤1 重新校准。
- `1_tracker_get_data/` 下的 `record.csv`（手动录制实例）、`tracker-full-screen.pptx`（操作说明）、`像素和现实尺寸转换.txt`（校准笔记）为真实实验资料，保留备查。

> 中文提示：已有 Tracker 导出的 CSV 时直接从步骤 2 开始；像素化是可选的展示美化步骤，不影响分析结果。
