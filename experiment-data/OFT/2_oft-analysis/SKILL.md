# OFT Step 2 — 数据分析与可视化

## Execution rule / 执行铁律

**Run the scripts in `scripts/` — do not write your own.**
The scripts here are the tested path; ad-hoc code generated by an agent is the
most common source of wrong results. Allowed changes, in order of preference:

1. Pass different CLI arguments (see Parameters below).
2. Copy the script to a scratch dir and make a **minimal** edit for a case the
   CLI cannot express — keep the change small and report exactly what changed.
3. Only if no script covers the task at all: write new code, run it, and then
   **fold it back into `scripts/`** so the next run reuses it.

每次执行前先读 `SKILL.md` 与 `examples/`；不要凭印象重写流程。

（中文摘要：本技能自带的 `scripts/` 是**经过验证的唯一推荐路径**。AI agent 执行时优先原样运行脚本、
只改命令行参数；确实需要改代码时，复制到临时目录做**最小改动**并说明改了什么；
只有完全没有对应脚本时才允许新写，且新写后必须回沉淀到 `scripts/`。禁止"凭印象重写一遍"。）

- 用户说「分析 OFT 数据」、「处理旷场实验」、「OFT 轨迹图」、「画旷场」
- 用户提供 Tracker 导出的 CSV 目录路径（来自步骤1）

## 前置依赖

- 输入数据来自 [步骤1：数据采集](../1_tracker_get_data/)
- 像素化后处理见 [步骤3](../3_oft-pixelate/)

## 工作流程

### S1: 单文件分析（plot_oft.py）

逐文件处理 Tracker CSV，输出：
- `arena_{样本名}.png` — 300dpi 轨迹图
- `arena_{样本名}.csv` — 结构化指标报告

```bash
python scripts/plot_oft.py <file.csv> [--px-per-cm 7.22] [--arena-size 50] [--total-duration 120] [--dpi 300]
```

### S2: 汇总表生成（generate_summary.py）

扫描目录树中所有 `arena_*.csv`，自动汇总。

```bash
python scripts/generate_summary.py <results_dir> [--output summary.csv]
```

## 输入格式

```csv
step,X,Y
1,925,421
2,929,471
...
```

## 依赖

- Python 3.8+
- matplotlib（其余仅用标准库；plot_oft.py 与 generate_summary.py 均不依赖 pandas/numpy/scipy）

## 默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| px_per_cm | 由 --arena-bounds 自动推算（默认边界下 ≈7.24） | 像素/厘米换算 |
| arena_size | 50 cm | Arena 边长 |
| total_duration | 120 s | 录制时长 |
| center_ratio | 0.40 | 中心区比例 |
| rest_threshold | 2.0 cm/s | 静止阈值 |
| dpi | 300 | 图片分辨率 |

## 注意事项

- **不修改原始代码** `plot_oft.py`
- Arena 边界默认值 `(908,384,1270,745)` 对应特定设置，更换摄像头/设置后需重新校准（见步骤1）
- 速度验证 WARNING 不拦截运行，仅供数据质量自查
