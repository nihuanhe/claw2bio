## What it does

Two-stage Western Blot densitometry workflow:

1. **ImageJ 宏测灰度**（`docs/wb_quantify_imageJ.ijm`）：在 ImageJ/FIJI 中手动框选条带 ROI，宏自动完成 8-bit 转换、Rolling Ball 去背景、反转、排序，导出含 IntDen 的 CSV。详见 `docs/ImageJ操作说明.md`。
2. **Python 归一化 + 统计 + 作图**（`scripts/wb_pipeline.py`）：读取整理好的灰度 CSV，每个目的蛋白除以内参（beta-actin）归一化，自动统计检验并生成带误差线、散点、显著性标注的 300 dpi 柱状图 PNG。

## Usage

```bash
# 单文件（输出默认写到输入 CSV 同目录）
python scripts/wb_pipeline.py <input.csv>

# 指定对照组名（用于 ≥3 组时 Tukey 检验写回 p_value）
python scripts/wb_pipeline.py <input.csv> --control "Ctrl"

# 指定输出目录
python scripts/wb_pipeline.py <input.csv> --output-dir <outdir>

# 批量模式：扫描目录下 FigureR*/FigureR*.csv
python scripts/wb_pipeline.py --batch <目录>
```

## Input format

由 ImageJ 灰度值人工整理成的 CSV，列名严格一致（`Mean_RepN` 列数自动检测，不限于 3 次重复）：

```csv
Protein,Sample,Mean_Rep1,Mean_Rep2,Mean_Rep3,beta_actin_mean
NOXA,Ctrl-BD-sEV,129.034,100.595,110.981,162.195
NOXA,Stress-BD-sEV,263.26,240.157,233.62,175.485
```

- `Protein`：目的蛋白名称（X 轴分组标签），数量不限
- `Sample`：分组/处理条件，支持 2–6 个
- `Mean_Rep1..N`：各次重复的 ImageJ 灰度 Mean 值
- `beta_actin_mean`：内参灰度值，同一 Sample 下所有 Protein 共享同一数值

## Output

- **归一化 CSV**：与输入同名（默认覆盖输入文件，`--output-dir` 可改目录），追加 `Normalized_RepX / Normalized_Mean / Normalized_SD / Normalized_SEM`、`p_value`、`Significance`（`ns/*/**/***`）；2 组时另有 `t_statistic/df`，≥3 组时另有 `ANOVA_F/ANOVA_p`
- **柱状图 PNG**：与 CSV 同名，300 dpi，含误差线（SD）、散点、显著性文字标注

## Statistics

- 归一化：`Normalized_RepX = Mean_RepX / beta_actin_mean`
- 2 个 Sample：Student's t-test（等方差）
- ≥3 个 Sample：单因素 ANOVA + Tukey HSD（vs `--control` 指定的对照组）

## Dependencies

Python 3.10+ with:


## Notes

- 若输入 CSV 已含 `Normalized_RepX` 列，归一化步骤自动跳过（幂等）。
- 配色为 Wong 2011 色盲友好方案，按 Sample 数自动选取。
- ImageJ 阶段的操作细节、宏参数（`autoSort` / `nCols` / `rollingBallRadius`）见 `docs/ImageJ操作说明.md`；完整计算流程的背景说明见 `docs/WB计算完整流程.md`。

> 中文提示：输入 CSV 的列名必须严格为 `Protein, Sample, Mean_Rep1..., beta_actin_mean`；默认输出会**覆盖**输入 CSV，如需保留原始数据请使用 `--output-dir` 或先备份。
