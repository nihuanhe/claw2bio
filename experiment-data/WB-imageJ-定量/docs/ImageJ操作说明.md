# Western Blot 灰度定量操作说明

## 参考教程

- [ivd.net 论坛 - Western Blot 灰度分析（ImageJ 方法）](https://www.iivd.net/forum.php?mod=viewthread&action=printable&tid=80534)

---

## 环境要求

- **ImageJ**（https://imagej.nih.gov/ij/）或 **FIJI**（https://fiji.sc/）
- 无需安装额外插件，仅使用软件内置功能

---

## 操作流程

### 步骤 1：打开图片
在 ImageJ 中手动打开 Western Blot 图片（`File` → `Open`，或直接拖入窗口）。

### 步骤 2：添加 ROI（手动操作）
在运行脚本之前，先完成 ROI 的框选：

1. 选择工具栏的**矩形选框工具**（或自由选区工具）
2. 框选一个条带
3. 按键盘 **`T`** 键，将其添加到 ROI Manager
4. 重复以上操作，框选所有需要定量的条带

> **关于顺序：**
> - 若脚本配置 `autoSort = true`：**框选顺序无关紧要**，脚本会自动按坐标排序
> - 若脚本配置 `autoSort = false`：**必须严格按行优先顺序添加**，即：
>   - 第 1 行第 1 列 → 第 1 行第 2 列 → 第 2 行第 1 列 → 第 2 行第 2 列 → ...

### 步骤 3：运行宏脚本
`Plugins` → `Macros` → `Run...`，选择 `wb_quantify_imageJ.ijm`（位于本技能 `docs/` 目录）

脚本将自动依次执行：
1. 转为 8-bit 灰度图
2. Subtract Background（Rolling Ball 去背景）
3. 设置测量参数（Area / Mean / Min / Max / Integrated Density）
4. 设置单位为像素
5. Invert（黑条带反转为亮条带）
6. 自动排序（若启用）并生成预览图
7. 测量所有 ROI 并导出 CSV

### 步骤 4：确认排序（仅 autoSort = true 时）
若启用自动排序，脚本会生成一张**预览图**，用红色数字标注每个条带的排序编号：

- 检查编号是否与实际条带对应（第 1 行应为 `1, 2`；第 2 行应为 `3, 4`...）
- 若正确，点击 **Yes** 继续测量
- 若错误，点击 **No** 取消，调整 `nCols` 参数后重新运行

### 步骤 5：查看结果
测量完成后，脚本自动生成 CSV 文件：

- **保存位置**：与当前打开的图片**同一文件夹**
- **文件名**：与图片文件名一致，仅扩展名改为 `.csv`

用 Excel 打开后，表格格式如下（示例）：

|  | Area | Mean | Min | Max | IntDen |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | 1234.000 | 185.234 | 120 | 245 | 228578.500 |
| 2 | 1156.000 | 172.456 | 110 | 238 | 199359.136 |
| ... | ... | ... | ... | ... | ... |

**Integrated Density（积分密度）**对应表中的 **IntDen** 列，即你需要的灰度绝对值。

## 配置参数（修改脚本顶部）

```javascript
autoSort = true;              // true = 自动按坐标排序; false = 严格使用 ROI Manager 顺序
nCols = 2;                    // 自动排序时，每行条带数（列数）
rollingBallRadius = 50;       // Subtract Background 半径
```

| 参数 | 说明 | 调整建议 |
|------|------|----------|
| `autoSort` | 是否启用自动坐标排序 | 条带排列整齐时开 `true`；排列不规则或仅需测部分条带时关 `false` |
| `nCols` | 每行条带数量 | 根据实际 WB 图列数设置（本图为 2 列） |
| `rollingBallRadius` | 背景扣除半径 | 图片较小（<500px）试 25；图片较大或背景不均试 100 |

---

## 注意事项

1. **ROI Manager 中请勿包含多余 ROI**：运行脚本前，删除所有非目标条带的 ROI，避免干扰排序和测量。
2. **Subtract Background 可能过校正**：如果发现条带 IntDen 异常偏低（甚至接近 0），说明 `rollingBallRadius` 过大，把条带信号也当背景减掉了，请调小后重试。
3. **预览图检查不可跳过**：自动排序后务必目视确认红色编号与条带对应，这是防止排序错误的最后防线。
4. **结果 CSV 为制表符分隔**：ImageJ 默认以制表符分隔列，Excel 可直接打开。如需纯逗号分隔 CSV，请在 Excel 中另存为。

## 批量处理提示

本脚本针对单张图片设计。若后续需要批量处理：
- 核心瓶颈在于**每张图都需要人工框选 ROI**，此步骤无法完全自动化
- 若所有图片条带位置固定，可预设固定坐标的 ROI，跳过手动框选
- 可将本脚本作为模板，配合 `getFileList()` 和循环语句实现文件夹级批处理
