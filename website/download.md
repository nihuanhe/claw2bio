# Download

Claw2Bio data is served in three tiers, so you never have to pull 50 GB through GitHub:

| Tier | Content | Where |
|---|---|---|
| **Mini examples** (in-repo) | A few MB per skill, runs in 30 s after clone | [GitHub repo](https://github.com/nihuanhe/claw2bio) |
| **Full datasets & per-skill zips** | Complete example data, standalone skill zips | Direct link on each skill's tutorial page (COS / this site) |
| **Academic archive** | Release snapshot with DOI | Zenodo — *coming soon* |

## Whole-library zip

*Not offered yet.* For most users we recommend the per-skill route instead:
open the tutorial page of the skill you need and use its **Get this skill** block.
