# Download

Claw2Bio data is served in three tiers, so you never have to pull 50 GB through GitHub:

| Tier | Content | Where |
|---|---|---|
| **Mini examples** (in-repo) | A few MB per skill, runs in 30 s after clone | [GitHub repo](https://github.com/claw2bio/claw2bio) |
| **Full datasets & per-skill zips** | Complete example data, standalone skill zips | Tencent COS direct links — *coming soon — being packaged* |
| **Academic archive** | Release snapshot with DOI | Zenodo — *coming soon* |
