# 下载

Claw2Bio 的数据分三层分发，无需从 GitHub 拉取 50 GB 整库：

| 层级 | 内容 | 位置 |
|---|---|---|
| **迷你示例**（随仓库） | 每个技能几 MB，clone 后 30 秒可跑 | [GitHub 仓库](https://github.com/claw2bio/claw2bio) |
| **全量数据与按技能 zip** | 完整示例数据、单技能独立 zip | 腾讯 COS 直链——*打包中，即将上线* |
| **学术存档** | 带 DOI 的发布版快照 | Zenodo——*即将上线* |
