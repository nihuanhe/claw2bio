# 无生物学重复（每组 n = 1）

## 会发生什么

任一组只有 1 个样本时，DESeq2/edgeR 的离散度估计在统计上不成立。
管线自动降级为**探索模式**：

- 引擎强制 limma-trend（log 表达上运行）；
- DEG 表只含 `baseMean` 和 `log2FoldChange`，`stat/pvalue/padj` 全为 NA；
- 火山图/MA 图/热图跳过（没有 p 值可画）；
- 控制台和 REPORT.md 顶部有显著双语警告。

## 红线

**n=1 的结果只能用于**：看趋势、挑候选基因做后续 qPCR 验证、决定要不要补重复。
**不能用于**：论文结论、通路富集的显著性声明、任何"p < 0.05"叙述。

## 常见场景与建议

| 场景 | 建议 |
|---|---|
| GEO 公共数据本身无重复 | 探索模式看趋势即可；找同课题其它数据集交叉验证 |
| 自己的数据重复被 QC 剔光了 | 回到实验层面解决，不要用探索模式凑数 |
| 部分组 n=1、部分组 n≥2 | 同样触发探索模式（最小组 n=1）；认真考虑 `--exclude-samples` 去掉无重复的组，保住其余组的正式分析 |
