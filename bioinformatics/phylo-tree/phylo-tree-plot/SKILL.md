# Skill: phylo-tree-plot (treefile + annotation → publication figure)

## Execution rule / 执行铁律

**Run the scripts in `scripts/` — do not write your own.**
The scripts here are the tested path; ad-hoc code generated by an agent is the
most common source of wrong results. Allowed changes, in order of preference:

1. Pass different CLI arguments (see Parameters below).
2. Copy the script to a scratch dir and make a **minimal** edit for a case the
   CLI cannot express — keep the change small and report exactly what changed.
3. Only if no script covers the task at all: write new code, run it, and then
   **fold it back into `scripts/`** so the next run reuses it.

每次执行前先读 `SKILL.md` 与 `examples/`；不要凭印象重写流程。

（中文摘要：本技能自带的 `scripts/` 是**经过验证的唯一推荐路径**。AI agent 执行时优先原样运行脚本、

## Trigger phrases

- draw / plot a phylogenetic tree with annotations
- ggtree circular tree with rings / heatmap rings
- 画进化树 / 系统发育树美化 / 树上加耐药基因环带

(Build the tree first with `phylo-tree-build` if all you have is FASTAs.)

## What it does

Input: ① a Newick treefile (tip labels = sample IDs), ② an annotation CSV
(first column `SampleID` matching tip labels; remaining columns = any
categorical annotations, `-` = none). Output: a publication-style figure —
midpoint-rooted tree, branches colored by a grouping column, one outer ring
per annotation column (auto color-ramp palettes), a standalone legend grid
below the tree, plus per-legend PNGs — as 600 dpi PNG and cairo-embedded PDF.

This is a **template script, not a CLI**: copy
`scripts/plot_tree_template.R` into the user's project and edit only the
`CONFIG (EDIT THIS BLOCK)` section — paths, `GROUP_COL`, `RING_COLS`,
colors, layout (`circular`/`rectangular`), geometry. Everything downstream
(ring count, palettes, legends, exports) adapts automatically.

## Environment

Windows R ≥ 4.1 (tested 4.5.2). Packages: ggtree + treeio (Bioconductor);
ggplot2, ggnewscale, RColorBrewer, viridis, cowplot, phytools (CRAN).
Quick check:

```r
stopifnot(all(c("ggtree","treeio","ggplot2","ggnewscale",
                "RColorBrewer","viridis","cowplot","phytools") %in%
              rownames(installed.packages())))
```

## Usage

```bash
# from the phylo-tree-plot skill directory (bundled example):
Rscript scripts/plot_tree_template.R
```

For user data: copy the template next to the user's files, set `TREEFILE`
and `ANN_CSV` in the CONFIG block, choose `GROUP_COL` / `RING_COLS`, run.

## Worked example (bundled, public data only)

`examples/input/` = the 12-genome public NCBI tree built by
`phylo-tree-build` (`main_tree/total_iqtree.treefile`) + `annotation.csv`
(public species metadata + contig-count bands, generated by
`scripts/make_example_annotation.py`). `examples/output/` = the figure PNG/PDF
from a real run, with REPORT.md. Console anchor: `tips: 12 | ring levels: …`.

## Input contract details

- Annotation CSV: header required; first column SampleID; categorical values
  only (continuous values should be binned first — each distinct value gets
  one palette color).
- Tips missing from the annotation (or vice versa) → hard `stopifnot` error;
  never silently drops tips.
- Genomes with no value for a ring column: use `-` (drawn in `RING_NA` grey).

## Troubleshooting

| Symptom | Fix |
|---|---|
| `stopifnot: all(tree$tip.label %in% ann$SampleID)` | SampleID mismatch — check filename stems vs CSV col 1 |
| `sum(is_tile) == n_rings` fails | A ring column has zero valid values, or gheatmap dropped an all-NA ring |
| Fonts missing in PDF (Arial) | cairo_pdf handles it; on non-Windows set `FONT <- "sans"` |
| Rings too thin / overlapping | Increase `RING_GAP` / `RING_WIDTH`, or enlarge `TREE_H_CM` |
| More than ~30 distinct values in a ring | Palette gets unreadable — bin the column or drop it |
