# REPORT — phylo-tree-plot example run (2026-09-16)

Example: the 12-genome public NCBI tree produced by `phylo-tree-build`
(copied to `examples/input/main_tree/total_iqtree.treefile`) +
`examples/input/annotation.csv` (public species metadata + contig-count
bands; generated by `scripts/make_example_annotation.py`, n = 12).

## Step executed

`Rscript scripts/plot_tree_template.R` (Windows R 4.5.2; ggtree/treeio/
ggplot2/ggnewscale/RColorBrewer/viridis/cowplot/phytools)

Console anchors: `rings drawn: 2 ( SpeciesGrp, ContigBand )` ·
`tips: 12 | ring levels: SpeciesGrp=7, ContigBand=3`

## Output files

| File | Purpose |
|---|---|
| `phylo_tree.png` | Final figure, 600 dpi (14 × 20.5 cm): midpoint-rooted circular cladogram, branches colored by Genus, 2 annotation rings (Species group / Contig count), legend grid below |
| `phylo_tree.pdf` | Same figure, cairo PDF (fonts embedded) |
| `phylo_tree_legend_*.png` | Standalone 600 dpi legends (Genus / SpeciesGrp / ContigBand) for reuse in composite figures |

Note: the template intentionally ships without tip labels (journal style for
large trees); add `geom_tiplab()` for small trees if needed.
