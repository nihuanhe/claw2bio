## What it does

This is a **resource skill**: it ships 100 ready-made mouse brain atlas coronal
line-art PNGs (Paxinos-style, Bregma +1.97 mm to -8.15 mm) in two versions, so
you can pick the plate matching your section's Bregma coordinate and overlay it
on a fluorescence/section image to annotate brain regions — no atlas software
or registration pipeline needed.

- `black_lines_only/` — 黑线图（白底），适合叠加到**亮场/浅色背景**图上
- `white_lines_only/` — 白线图（同名同坐标），适合叠加到**暗背景荧光**图上

The bundled script converts black-line atlas pages into transparent-background
white-line PNGs (useful when you need a custom plate or want to re-derive the
white version).

## Usage

### 选图叠加（主用途，无需跑脚本）

1. 确定脑片的 Bregma 坐标（如 -1.55 mm）。
2. 从 `black_lines_only/` 或 `white_lines_only/` 取同名 PNG
   （如 `Bregma_-1.55mm.png`）。
3. 在 ImageJ/Photoshop/Illustrator 里把线图叠加到荧光图上，对齐 landmarks
   （中线、脑室、海马外形）后标注脑区。

### 黑线图 → 透明底白线图（转换脚本）

```bash
# 单张
python scripts/convert_bregma_to_white_lines.py black_lines_only/Bregma_+0.01mm.png <输出目录>

# 批量（默认输出到 <输入目录>/white_lines_only/）
python scripts/convert_bregma_to_white_lines.py --batch black_lines_only [输出目录]
```

每张输入产两个文件：`atlas_<坐标>_white_lines_only.png`（透明底白线）和
`_preview_on_black_<坐标>.png`（黑底预览，供快速目检）。

## Input / Output

- 输入：无必需输入（资源型技能）；转换脚本接受 `Bregma_*.png` 图谱页
- 输出：叠加用 PNG 直接使用；转换脚本输出透明底白线图 + 黑底预览图

## Dependencies

转换脚本需要 Python 3.10+：

```bash
pip install numpy pillow
```

（选图叠加主用途不依赖任何软件环境，用 ImageJ/Photoshop 均可。）

## Notes

- 两版图谱各 100 张，文件名完全一致（`Bregma_±X.XXmm.png`），按坐标一一对应。
- 转换脚本阈值 `GRAY_MAX = 169`（黑线 ~≤64、灰填充 ~128–169），若自有 atlas
  页底色不同，复制脚本到临时目录微调该阈值即可。
- 叠加后请人工核对脑区边界——atlas 是参考线图，最终标注以你的组织学判断为准。

> 中文提示：主用途是「按 Bregma 坐标选线图 → 叠加到荧光图 → 标注脑区」，不需要跑任何代码；
> 转换脚本只在需要把黑线图变透明底白线图时使用。
