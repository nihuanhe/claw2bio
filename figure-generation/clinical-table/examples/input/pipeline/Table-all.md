# Table-all.md — skeleton (empty numeric cells) for the R table suite

> This file is the working template of the R suite (table1_baseline.R …
> table10_plasmid_replicons.R): each script greps its own
> `## ... (revised/new)` heading, keeps the header and separator lines
> verbatim, validates the first-column labels, and rewrites the body rows.
> It was generated from the final Word files
> (`main_revised_clean.docx` / `supplement_revised_clean.docx`), publication-style
> captions only; the (revised)/(new) qualifiers are internal to the R grep.
> Table numbering: Table 1/2 = manuscript Table 1/2; Table 3–10 = manuscript
> Supplemental Tables S1–S8 (Table 9 = S7, the standalone annex).

**Run order (each script alone, in order):** table1_baseline.R →
table2_firth.R → table3_esbl_genes.R → table4_sequence_types.R →
table5_sul_genes.R → table6_disease_genotype.R →
table7_procedures_genotype.R → table8_univariate.R →
table10_plasmid_replicons.R.  Table 9_sequencing_quality is a per-isolate
annex regenerated by `make_table9_sequencing_quality.py` (not part of the
R suite).
