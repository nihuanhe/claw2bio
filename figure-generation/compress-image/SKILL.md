## 功能

将高分辨率科学图像（如无压缩 TIFF）转换为文件更小的格式，默认 JPEG 85%，肉眼基本无损，并保留 300 dpi 元数据。

## 使用方式

### 默认：TIFF 转 JPEG 85%

```bash
python scripts/compress_image.py <input.tif> <output.jpg>
```

### 指定 300 dpi

```bash
python scripts/compress_image.py <input.tif> <output.jpg> --dpi 300
```

### 无损 TIFF ZIP（适合存档/分析）

```bash
python scripts/compress_image.py <input.tif> <output.tif> --format tiff_zip
```

## 参数

| 参数 | 说明 | 默认值 |
|---|---|---|
| `input` | 输入图像路径 | 必填 |
| `output` | 输出图像路径 | 必填 |
| `--quality` | JPEG 质量 1–100 | 85 |
| `--format` | `jpeg`、`tiff_lzw`、`tiff_zip`、`png` | jpeg |
| `--dpi` | 输出 DPI | 继承输入或 300 |

## 注意事项

- JPEG 不适合作为需要后续定量分析的原始数据；分析场景请用 `--format tiff_zip`。
- 若输入已是压缩 TIFF，再次压缩收益有限。
